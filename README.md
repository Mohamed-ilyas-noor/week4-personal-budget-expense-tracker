# SpendWise Dashboard Shell

## Project Description

SpendWise is a Personal Budget and Expense Tracker. This week I built the Dashboard Shell using HTML and modern CSS layout techniques.

The dashboard contains a sidebar navigation menu, a header, six financial category cards, and a recent activity section.

## Files

### index.html

The `index.html` file contains the structure of the SpendWise Dashboard.

It includes:

- SpendWise sidebar
- Navigation menu
- Dashboard header
- Total balance
- User profile
- Food category card
- Transport category card
- Rent category card
- Entertainment category card
- Savings category card
- Utilities category card
- Recent activity section

### style.css

The `style.css` file controls the visual design and layout.

It includes:

- CSS Grid for the main dashboard layout
- CSS Grid for the category cards
- Flexbox for the sidebar
- Flexbox for the header
- Flexbox for the dashboard cards
- CSS custom properties
- Responsive media queries
- Hover effects
- Keyboard focus effects
- Card shadows
- Card animations
- Responsive mobile layout

## CSS Custom Properties

The project uses CSS variables for the main theme:

- Brand color
- Accent color
- Surface color
- Background color
- Primary text color
- Secondary text color
- Border color
- Success color

## Responsive Design

The dashboard changes to a single-column layout below 768px.

The layout can be tested using the browser's DevTools Device Toolbar.

## Micro-interactions

Dashboard cards have subtle hover and keyboard focus effects.

The effects use:

- `transform`
- `box-shadow`
- `transition`

The animation duration is 200ms.
